# Research method

1. Bind the question to the thread before searching (place, units, pronouns).
2. Prefer structured APIs (weather, memory) over SERP titles.
3. Search, then read 1–2 official pages. GitHub, Codelabs, Kaggle, grokipedia, Microsoft Learn beat blogs.
4. Coverage is the share of query terms that appear in observation text. Below ~0.55, run gap_search.
5. Stop gathering once coverage is adequate and numbers/yes-no are supported. Extra searches after that add noise.
6. Never invent tool results. If a page is a login wall, skip it.
