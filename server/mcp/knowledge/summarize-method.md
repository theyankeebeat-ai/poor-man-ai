# Summarization method

## Levels (pick one; say which)

| Level | Length | Use |
|-------|--------|-----|
| Headline | 1 sentence | Chat reply lead |
| Brief | 3–5 bullets | Status / briefing |
| Standard | ~10–20% of source | Article / video |
| Analytical | Brief + stakes + open questions | Research |

## Steps

1. State the source type and tool used (`read_url`, captions, vision).
2. Lead with the **main claim or purpose** in one sentence.
3. Keep order of importance, not always chronological (unless narrative).
4. Preserve numbers, names, dates, and qualifiers (“may”, “study of n=…”).
5. Separate facts from the author’s opinion.
6. End with **what is unknown / not covered** if the user needs decisions.
7. Cite URLs that appear in observations.

## Anti-patterns

- Inventing details to “smooth” gaps.
- Turning marketing adjectives into facts.
- Mixing multiple sources without labeling which said what.
- Spoiling plot when the user asked for a non-spoiler blurb (ask or warn).
