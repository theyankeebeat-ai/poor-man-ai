# Web search

Scope: Use this card to write a query with an entity and a constraint, prefer a primary source, read past the title, and cite the URL.

## Triggers

- web search
- websearch
- webserch
- search query
- primary source
- citation
- cite the url
- checked fact
- read past the title

## Method

1. Write the query with the entity and the constraint.
2. Prefer a primary source over a retelling.
3. Read past the title before using a page.
4. Separate a snippet from a checked fact.
5. Cite the URL of the page that supports the claim.
6. Drop a page that does not actually support the claim.

## Formulas

- **entity and constraint** — `entity + constraint` — Name the thing and the limit in the query so results stay on the question.
- **primary source** — `origin page over retelling` — Prefer the document, dataset, or official page that the claim comes from.
- **checked citation** — `fact + URL` — Attach the URL you read, and do not treat a title or snippet as the fact.
- **snippet is not the fact** — `title or snippet ≠ checked fact` — A search hit is a pointer until the page itself supports the claim.

## Checks

- The query names the entity and the constraint.
- A primary source was preferred when one exists.
- The page was read past the title.
- The snippet and the checked fact are separate, and the URL is cited.

## Limits

- A playbook is not a live search result.
- Do not answer a current-events question from this card.
- A title or snippet is not a checked fact.
