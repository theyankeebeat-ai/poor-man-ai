# Communication

Scope: Use this card to fit a message to an audience and to name a misunderstanding before disagreeing.

## Triggers

- communication
- active listening
- misunderstanding
- audience
- facts and tone
- restate the point
- message and channel

## Method

1. Name the audience, purpose, message, channel, and feedback.
2. Say the point in words that audience can use.
3. Restate the other person's point before disagreeing.
4. Name the misunderstanding in one plain line.
5. Separate facts from tone.
6. Ask what feedback would show the message landed.

## Formulas

- **message frame** — `audience + purpose + message + channel + feedback` — Check who it is for, why you are sending it, what it says, where it goes, and how you will know it landed.
- **listen then differ** — `restate the point, then disagree` — Active listening repeats the claim in fair words before any objection.
- **facts apart from tone** — `facts != tone` — State what was said or done separately from how it sounded.
- **feedback check** — `sent message vs received message` — Compare what was sent with what the other person understood, and name the gap.

## Checks

- Audience, purpose, message, channel, and feedback are named.
- The other point is restated before any disagreement.
- The misunderstanding is named, not only felt.
- Facts and tone are kept separate.

## Limits

- This card shapes a message; it does not decide the facts.
- Restating a point is not the same as agreeing with it.
- Do not treat tone as evidence.
