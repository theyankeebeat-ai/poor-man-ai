# Algebra

This card solves linear, system, exponent, and quadratic questions from the coefficients and points already given.

## Method

1. Classify the problem as a line, a system, a polynomial, or a quadratic.
2. Copy the given coefficients, points, and equations without filling blanks.
3. For two points with different x-values, compute the slope, then write y = mx + b.
4. For a system, use substitution or elimination and satisfy every equation.
5. For ax^2 + bx + c = 0 with a not zero, compute the discriminant, then the quadratic formula.
6. Substitute the result into the original equation before stating it.

## Formulas

- **Slope**: `m = (y2-y1)/(x2-x1)` — Slope is the change in y divided by the change in x between two points.
- **Slope-intercept form**: `y = mx + b` — A line with slope m crosses the y-axis at b.
- **Quadratic formula**: `x = (-b ± sqrt(b^2 - 4ac)) / (2a)` — Gives the roots of ax^2 + bx + c = 0 when a is not zero.
- **Discriminant**: `b^2 - 4ac` — A positive value means two real roots, zero means one real root, and a negative value means no real roots.
- **Exponent product rule**: `a^m * a^n = a^(m+n)` — Multiplying powers of the same base adds the exponents.

## Checks

- Slope is undefined when x2 = x1; do not divide by zero.
- The quadratic formula needs a ≠ 0; a zero leading coefficient is a linear equation.
- A positive discriminant gives two real roots, zero gives one, and a negative gives none in the reals.
- a^m * a^n = a^(m+n) only when the bases match; the product is not a^(mn).

## Limits

- The quadratic formula finds roots, not the vertex by itself.
- A system contains only the equations written down, not extra constraints.
- This card does not supply a coefficient, point, or exponent the user did not give.
