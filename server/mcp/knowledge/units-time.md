# Units and time

- Default units: metric (°C, mm) unless the user or thread said F/imperial.
- Convert with °F = °C × 9/5 + 32. Report in the user's units only.
- “Today / tonight / now” means current observations, not last week's blog.
- Follow-ups inherit place and units unless the user changed topic.
- If sources disagree by more than ~3°C, say the range; do not pick one silently.
