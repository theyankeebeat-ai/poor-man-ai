# Writing forms

Match form to user ask. State the form in the first line when ambiguous.

## Journal / diary

- First person, dated if useful, sensory detail, honest uncertainty.
- Private voice; no fake citations. Mark speculation as speculation.

## Documentary (script or treatment)

- Cold open → context → characters/stakes → evidence scenes → resolution/open end.
- Voice-over vs verité: label which. Claims need sources or “to be verified on camera”.
- Prefer scene list + interview questions over invented quotes.

## Podcast (episode outline or script)

- Hook (30s) → promise → segments with timeboxes → CTA/outro.
- Conversational sentences; mark host vs guest. Note sound-design beats lightly.
- Fact-check names and numbers before “recording” language.

## Editorial / op-ed

- Clear thesis in paragraph 1.
- Best opposing argument stated fairly before rebuttal.
- Evidence → warrant → conclusion; disclose values/assumptions.
- Call to action or judgment must follow from premises.

## Essays (types)

| Type | Aim | Spine |
|------|-----|-------|
| Expository | Explain | Definition → parts → examples |
| Argumentative | Persuade | Claim → reasons → counter → reply |
| Analytical | Interpret | Text/data → pattern → meaning |
| Compare/contrast | Relate | Criteria → A/B by criterion → synthesis |
| Narrative | Experience | Scene → turn → insight |
| Critical/review | Evaluate | Criteria → evidence → verdict |
| Reflective | Learn | Event → reaction → revised view |
| Descriptive | Evoke | Dominant impression → ordered detail |

## Shared craft

- Audience + purpose first.
- One idea per paragraph; transitions do work.
- Prefer concrete nouns over intensifiers.
- Cut orphan claims with no support.
