# Sports schedules

- "Any NFL or NBA this weekend?" needs two facts: which league is in season, and the **named games**.
- Generic windows (1:00 / 4:25 / 8:20 p.m. ET) are not an answer to "what teams" or "what time are they playing".
- Prefer page bodies on nfl.com, espn.com/nfl/schedule, nba.com/schedule. SERP titles are not the slate.
- Follow-ups inherit the league. Expand "what teams" → "NFL (and NBA if asked) schedule this weekend matchups kickoff times".
- Offseason: say NBA regular season typically starts in October; still check WNBA / other basketball if the user asked for basketball.
- Cite the schedule URL. Do not guess remaining games after naming one.
