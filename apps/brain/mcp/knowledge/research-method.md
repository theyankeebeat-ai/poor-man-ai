# Research method

1. Bind pronouns and missing subjects before searching. Do not paste the previous question into a search that already names its subject.
2. Prefer structured APIs (weather, memory) over SERP titles.
3. Search, then read 1–2 official pages. GitHub, Codelabs, Kaggle, grokipedia, Microsoft Learn beat blogs.
4. Coverage is the share of query terms that appear in observation text. Below ~0.55, run gap_search.
5. Stop gathering once coverage is adequate and numbers/yes-no are supported. Extra searches after that add noise.
6. Never invent tool results. If a page is a login wall, skip it.
7. A one-edit misspelling should still match. A different given name should not. Use the spelling in the sources.
8. If hits describe different events, keep more than one. Do not let one headline fill the list.
9. A number stated for one condition is not the value for another condition, and not the value of the change from one to the other.
