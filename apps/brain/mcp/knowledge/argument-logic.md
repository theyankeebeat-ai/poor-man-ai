# Argument, compare, conclude, synthesize

## Compare

1. Fix **shared criteria** before listing differences.
2. Table or parallel bullets: criterion → A → B.
3. End with what the criteria imply for the user’s goal (not a forced winner).

## Contrast

- Emphasize meaningful divergences only (mechanism, outcome, cost, risk, values).
- Avoid false dichotomies; name hybrids when they exist.

## Debate

1. Steelman each side in 2–4 claims with best evidence.
2. Identify burden of proof and shared facts.
3. Attack weakest **warrant**, not the person or a strawman.
4. Use `agent_talk` / blackboard when specialists disagree.
5. Score: supported / contested / unsupported via `extract_claims` + `compare_sources`.

## Be impartial / fair / consistent / objective

- Impartial: same standards for all sides.
- Fair: present the strongest opposing case before rebutting.
- Consistent: same definitions and metrics throughout.
- Objective: prefer observable/tool-backed claims; label value judgments as such.

## Conclude

A conclusion is not a summary dump. It must:

1. Restate the question.
2. Give the answer in one direct sentence.
3. List the 2–4 reasons that carry the weight.
4. State residual uncertainty and what evidence would change the answer.

## Synthesis

Merge sources into a **new structure** (timeline, causal chain, decision matrix), not a stitch of quotes.

1. Cluster agreeing claims; note outliers.
2. Resolve conflicts with source-trust order (see `source-trust`).
3. Produce one coherent account + “dissenting notes”.
4. Cite the URLs that actually support each pillar.
