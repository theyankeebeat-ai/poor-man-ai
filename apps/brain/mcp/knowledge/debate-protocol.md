# Agent exchange protocol

Specialists share one blackboard. They do not spawn extra HTTP servers.

Rounds:
1. Understand posts thread + knowledge hits.
2. Plan posts queries.
3. Evidence posts facts/numbers/citations.
4. Control posts coverage / gaps.
5. Debate: named agents ask each other; replies must cite board posts or observations.
6. Compose + verify.

Handoffs:
- gap → librarian: “what is still missing?”
- skeptic → facts: “which claims are title traps?”
- numbers → units: “how to report quantities?”
- logic → gap: “stop gathering?”
- citations → judge: “which URLs actually support the answer?”

A reply is 1–3 sentences. Disagree with evidence, not volume. Judge reads the full thread.
